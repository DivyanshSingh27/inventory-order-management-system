# Inventory & Order Management System

A microservices-based Inventory and Order Management System developed using Java, Spring Boot and PostgreSQL.

## Microservices

### 1. Inventory Service
Handles inventory-related operations.

### 2. Authentication Service
Handles authentication and authorization.

### 3. Order Service
Manages order processing and related operations.

### 4. Notification Service
Handles notification-related operations.

## Technology Stack

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- REST APIs
- Maven
- Docker

## Project Structure

```text
inventory-order-management-system/
├── inventory-service/
├── auth-service/
├── order-service/
├── notification-service/
└── README.md
```

## Getting Started

Each microservice has its own Maven configuration (`pom.xml`) and can be built independently.

Refer to the individual service directories for configuration and execution instructions.
